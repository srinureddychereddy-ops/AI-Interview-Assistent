Problem Statement

Two Sum

Medium
Time Limit: 1s Memory Limit: 256MB
Description

Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

Input Format

The first line contains an integer `n`, the size of the array. The second line contains `n` space-separated integers. The third line contains the `target` integer.

Output Format

Return the two indices as a space-separated string.

Constraints
  • `2 <= nums.length <= 10^4`
  • `-10^9 <= nums[i] <= 10^9`
  • `-10^9 <= target <= 10^9`
  • Only one valid answer exists.
Sample Input
2 7 11 15
9
Sample Output
0 1
